import matplotlib.pyplot as plt
import numpy as np

try:
    # Attempting to plot arrays of different lengths

# 4. Two Print Successes
print("\n--- Step 4: Print Successes ---")

plt.colorbar(label="Intensity")
plt.title("2D Array Imshow Plot")

### Code Explanation

1. **Print Mistake (`TypeError`):** Python is strongly typed. Attempting to use the `+` operator to combine a string (`"The score is: "`) and an integer (`100`) forces a hard crash. You must explicitly cast the integer using `str(100)` or use an f-string (`f"The score is: {100}"`).
2. **First Plot:** A standard line plot is generated successfully on `Figure 1` because the X and Y lists have the exact same number of elements (3).
3. **plt Mistake (`ValueError`):** The `plt.plot()` function requires the `x` and `y` arrays to have identical dimensions. Passing an array of 4 items for X and 2 items for Y causes matplotlib to crash because it cannot map the coordinates.
4. **Print Successes:** Standard, error-free string prints execute normally.
5. **Final Plot (`imshow` and `savefig`):**
* `plt.imshow()` takes a 2D array (like a matrix or a loaded image file) and maps the numerical values to colors using a colormap (`cmap='plasma'`).
* `plt.savefig("filename.png")` writes the current active figure to your hard drive. This must be called *before* `plt.show()`, because `show()` often clears the figure buffer from memory once the window is closed, which would result in saving a blank image.
